## 已完成

- HTTP Client 连接池：`LazyLock<reqwest::blocking::Client>` 全局复用
- 流式 Tool Call 参数累积：分离 id/name/arguments，支持 chunk 拼接
- 错误类型枚举：`LlmError` + `ToolError`（`thiserror`），含 `is_retryable()`
- Config 启动时缓存：`CONFIG_CACHE` 避免每次 LLM 调用读磁盘
- CI/CD：GitHub Pages 部署 workflow
- App.tsx 拆分：3,090 → 1,044 行，提取 11 个文件（hooks + components + lib）
- Pipeline 简化：去掉 JSON 中间校验，summary/world 统一 Markdown 直出
